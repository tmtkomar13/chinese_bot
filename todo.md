# После ночной загрузки GIF

- [ ] **GIF в ВК.** На нетбуке сверить вывод `gif-status` для всех трёх скоростей. Проверить доставку готового GIF в карточке. При сообщении «Готовлю GIF» оставить карточку открытой до получения вложения. Если вложение не придёт, проверить журнал службы `chinese-trainer`.
- [ ] **Пропись на телефоне.** Задать адрес страницы в `STROKES_PAGE_URL` на нетбуке и перезапустить бота. Через «Порядок черт» открыть 你好 и пройти слово один раз по контуру, затем три раза по памяти. Проверить автоматический переход от 你 к 好 в каждом проходе.
- [ ] **Доступ вне домашней сети.** Проверить публичный IP и доступность входящих подключений. Если они доступны, настроить домен и HTTPS через Caddy. При CGNAT использовать исходящий туннель. Указать публичный HTTPS-адрес в `STROKES_PAGE_URL`, перезапустить бота и пройти пропись из ВК на телефоне с выключенным Wi-Fi.
